# Hupeyaszih Neural Network

Hupeyaszih Neural Network is an event-driven neural network architecture, inspired by biological brain (like SNNs), aims to make a real artificial intelligence with energy efficiency, better adaptive learning abilities, and neural plasticity.

---
> [!WARNING]
> **Current Phase: The project is no longer under development**

## Why the Project is Ended

The reason is simple: it is hard (nearly impossible) to run such a complex system on classical computers, which is the biggest problem of SNN-like neural networks. Whatever you do, AGI cannot be achieved with this architecture, whereas biological computers increase their value and importance.

## Why This is Needed
While Large Language Models (LLMs) and other architectures have achieved remarkable results, they suffer from fundamental architectural bottlenecks:
- **Lack of Plasticity**: Standard deep learning architectures strictly separate training and inference passes. They cannot adapt dynamically in real-time during execution, also they are slow.
- **Energy Efficiency**: Standard architectures using much energy,because of dense matrix multiplications etc., compared to biological brain. This creates a huge issue about them, they are unsustainable.

Consequently, HNN is fundamentally different, like night and day. It uses less energy, has neural plasticity, inspired by the biological brain, which has been refined by evolution over hundreds of millions of years.

## Limitations and Differences
Although HNN is better than LLMs and aims to mimic the biological brain, LLMs are better in some cases; here are some examples:
- LLMs and other deep learning models are better when it comes to predictions by pattern recognition etc.
- HNN is better because it doesn't much need data to learn as much as LLMs need. Also, it is creative, like us. It can learn with less data.

There are other limitations and differences compared to other neural network models, but this doesn't change the situation. The real intelligence is absolutely what biological brain is, which is creative.
